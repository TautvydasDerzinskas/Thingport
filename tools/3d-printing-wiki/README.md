# 3D Printing Wiki

Install **3D Printing Wiki** from **Administration → Tools** and open it from **Tools**. The wiki covers fused filament fabrication (FDM/FFF). It includes material guides, practical workflows for splitting models and slicing, CAD, printer makers, a History section and a glossary. Search matches article titles and contents.

Troubleshooting groups 32 cases by symptom. Each case has an observable diagnostic check, likely causes, a sequence of fixes and a way to verify the result. Eighteen cases have illustrations. Printer profiles cover common desktop models, open-source kits, toolchangers and industrial FDM, with links to the makers’ documents.

The practice quiz draws 30 questions from a 108-question bank and shuffles the answer choices. Every attempt includes four illustrated diagnosis questions. It uses 20 one-point questions, five two-point scenarios and five three-point multi-select questions. Select both correct answers to earn all three points. The pass mark is 36 of 45 points. The review gives explanations, relevant defect images and links to the full articles. Quiz progress stays in the open window.

The settings guides include controlled Bambu Studio 02.09.01.70 slice comparisons. Use a 40 × 30 × 24 mm solid block, Bambu Lab A1 with the 0.4 mm nozzle, Bambu PLA Basic, and the A1 0.20 mm Standard process. Set the initial layer to 0.20 mm, two walls, 15% grid infill, three minimum top and bottom layers with 0.80 mm minimum thickness, and no brim or supports. Change only the setting shown in each comparison. Time and filament values come from the sliced G-code’s reported model time and filament weight.

The [Top 3D Shop FDM overview](https://top3dshop.com/blog/fused-deposition-modeling-all-you-need-to-know-about-fdm-3d-printing-technology#anchor23) and the [r/3DPrinting community wiki](https://www.reddit.com/r/3Dprinting/wiki/index/) informed the topics. The articles link to the slicer or material maker’s documentation for technical settings.

A passing attempt requests **FDM Fundamentals** through Thingport’s achievements SDK. With a status-aware host, a learner can retry an unconfirmed claim from the same result. Hosts with the older boolean SDK still support the initial claim. This award uses the SDK’s client-triggered badge mechanism.

## Packaging

The tool ships its text and images in the installed script and markup. The references are optional links readers can open. The defect images in `source/images/` are AI-generated illustrations of FDM symptoms. The guide text is original and links to manufacturer documentation and primary sources in the relevant articles.

Edit the content and window markup in `source/`. Rebuild the installable script and HTML with `node tools/3d-printing-wiki/source/build.mjs` and run `node tools/3d-printing-wiki/source/test_wiki.mjs` from the repository root.
