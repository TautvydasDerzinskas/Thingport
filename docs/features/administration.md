# Administration

Every instance-wide setting lives under **Administration**, in the sidebar, with a page for each part of Thingport. The
first account on an instance is its admin, and there's no config file to edit after the first start.

| Page         | What it's for                                                                                                                                                                                                                                                                                                                               |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Overview     | [System Health](../guides/system-health.md) for everything Thingport relies on, disk space used, and the update check, which says when newer Thingport images are out. **What's new** there reopens the notes of the running version, which everyone is offered after an update.                                                            |
| Providers    | Turn any of the 17 sites Thingport imports from off for everyone, and set the Thingiverse App Token and the MyMiniFactory API key. See [turning a provider off](../PROVIDER_SETUP.md#turning-a-provider-off).                                                                                                                               |
| Storage      | The folder layout on disk, reorganizing existing files, browsing the storage folder, copy-on-write clones of identical files and pictures (also for files stored before), and the [consume folder](../guides/consume-folder.md). See [plain files on your disk](storage.md).                                                                |
| Auth         | The public URL, open or invite-only registration, [single sign-on](../guides/single-sign-on.md) providers, and how long a sign-in lasts.                                                                                                                                                                                                    |
| Rendering    | How card thumbnails are made, simplifying the previews of very detailed models, and [print quality checks](print-quality.md): on or off, and which problems to look for. See [3D previews](3d-previews.md).                                                                                                                                 |
| Dashboard    | Whether users may make their own [custom dashboard widgets](../guides/custom-widgets.md) and install community ones, and which widgets are in use.                                                                                                                                                                                          |
| Tools        | Who sees [tools](../guides/tools.md) and whether they may make their own, and the tools in the repository: install one, with or without the models it brings, and update it from its tile, which says **Update** when there's a newer version and **Latest** when there isn't. An update brings a tool's models only if they were imported. |
| AI           | AI models and the [AI features](../guides/ai.md): categorization and improved descriptions.                                                                                                                                                                                                                                                 |
| Users        | Everyone's accounts, roles and sign-in methods. See [multi-user](multi-user.md).                                                                                                                                                                                                                                                            |
| Import queue | Opens the [import queue](importing.md#the-import-queue) on **Everyone**: every person's imports, to start, hold, pause, retry or delete. Everyone also has a queue of their own, from the top bar.                                                                                                                                          |
| Logs         | What each person did, by person and date: sign-ins, imports, edits, deletions, syncs, repairs, role changes, provider switches and AI runs.                                                                                                                                                                                                 |
| Triggers     | One-off maintenance jobs: link missing authors, refetch imported descriptions, or delete all of a user's models.                                                                                                                                                                                                                            |
| Connections  | FlareSolverr, email (SMTP) and the database, each tested before it's saved. Switching the database is refused while anything is importing.                                                                                                                                                                                                  |
| Captcha      | Where to ask for a captcha: sign-in, registration, import, and password and email changes.                                                                                                                                                                                                                                                  |

After installing, and whenever something stops working, start with
[System Health](../guides/system-health.md): ideally everything there is green.

For a tour with screenshots, see [thingport.net/features/administration](https://thingport.net/features/administration/).
